Windows에서 출력 장치·마이크·앱별 볼륨을 프로필 한 번으로 바꾸는 도구, DesktopAudioController

Windows에서 오디오 장치를 여러 개 쓰다 보면
"지금 이 장치에서 어떤 프로그램이 소리를 내고 있는지",
"특정 프로그램만 빠르게 음소거하거나 볼륨을 조절하고 싶은데 너무 번거롭다",
"스피커에서 이어폰, 이어폰에서 헤드셋으로 바꿀 때마다 출력·마이크·볼륨을 일일이 다시 맞춰야 한다"
같은 불편이 자주 생깁니다.

그래서 직접 만든 도구가 DesktopAudioController입니다.

이 프로그램은
사용자가 고른 출력 장치만 메인 화면에 표시하고,
각 장치의 마스터 볼륨과
그 장치에서 실제로 소리를 내는 프로그램별 볼륨을 빠르게 제어할 수 있게 해 주며,
자주 쓰는 장치 조합을 프로필로 저장해 버튼 하나로 바꿀 수 있는 Windows 전용 데스크톱 유틸리티입니다.

어떤 점이 편한가

1. 필요한 출력 장치만 골라서 표시
Windows에는 실제로 쓰지 않는 장치나 가상 장치가 섞여 있는 경우가 많습니다.
설정에서 장치를 선택하면 선택한 장치만 메인 화면에 표시하고,
지금 Windows 기본 출력 장치는 항상 맨 위에 보여 줍니다.

2. 장치 볼륨과 프로그램 볼륨을 한 화면에서 제어
각 장치마다 다음 작업을 바로 할 수 있습니다.

* 마스터 볼륨 조절
* 장치 음소거
* 기본 출력 장치 전환
* 해당 장치에서 출력 중인 프로그램별 볼륨 조절
* 프로그램별 음소거
* 프로그램별 출력 장치 변경 (예: 게임은 이어폰, 브라우저는 스피커)

즉,
"스피커 전체 볼륨은 유지하고 브라우저만 줄이기",
"특정 장치에서 재생 중인 앱만 골라서 음소거"
같은 작업이 훨씬 빨라집니다.
프로그램별로 맞춰 둔 볼륨은 저장되어, 장치를 바꾸거나 프로그램을 다시 켜도 바로 다시 적용됩니다.

3. 프로필 한 번으로 스피커 ↔ 이어폰 ↔ 헤드셋 전환 (v0.19 새 기능)
자주 쓰는 장치 조합을 프로필로 저장해 두면, 한 번에 아래를 모두 바꿉니다.

* 기본 출력 장치 (Windows '기본 장치'와 '기본 통신 장치'를 함께)
* 기본 입력 장치(마이크) — 디스코드처럼 통신 장치를 쓰는 앱도 같이 따라옵니다
* 장치가 없을 때 대신 쓸 장치 순서 — 헤드셋을 꺼 둔 채 눌러도 이어폰이나 스피커로 대신 나오고 알림으로 알려 줍니다
* 장치 볼륨·음소거 — 예: 이어폰은 20%로 시작(귀 보호), 이어폰 프로필에서는 스피커 음소거
* 프로그램별 출력 장치와 프로그램별 볼륨 저장값

예를 들면 이렇게 씁니다.

* 1. 스피커: 기본 출력 = 스피커
* 2. 이어폰: 기본 출력 = 이어폰(없으면 스피커), 이어폰 20%, 스피커 음소거
* 3. 헤드셋: 기본 출력 = 헤드셋(없으면 이어폰 → 스피커), 마이크 = 헤드셋 마이크

4. 프로필을 바꾸는 방법도 여러 가지
상황에 맞게 편한 방법으로 바꾸면 됩니다.

* 메인 화면 위쪽 프로필 버튼 (지금 프로필은 파란색으로 표시)
* 트레이 아이콘 우클릭 메뉴에서 바로 선택
* 전역 단축키 (예: Ctrl+Alt+1 ~ 3, 다른 프로그램과 겹치면 안내)
* 명령으로 적용 — 엘가토 스트림덱 같은 버튼 장치의 "열기" 동작에 넣어 쓸 수 있습니다

   DesktopAudioController.exe --profile "헤드셋"
   DesktopAudioController.exe --profile-index 2
   DesktopAudioController.exe --toggle-mute "스피커"

   앱이 이미 켜져 있으면 새 창 없이 명령만 전달하고, 꺼져 있으면 트레이로 조용히 시작한 뒤 적용합니다.
   키 입력이 아니라서 관리자 권한으로 실행된 게임이 앞에 있어도 막히지 않습니다.

5. 트레이에서 볼륨을 10% 단위로 바로 선택
트레이 아이콘 우클릭 → "현재 출력 장치 볼륨"에서 0~100%를 10% 단위로 바로 고를 수 있습니다.
Windows 볼륨 믹서나 키보드 볼륨 키로 바꾼 값도 메인 화면과 트레이에 바로 반영됩니다.

6. 조용한 앱도 유지할지, 재생 중인 앱만 볼지 선택 가능
프로그램 세션은 순간적으로 소리가 멈췄다고 목록에서 바로 사라지면 오히려 불편할 수 있습니다.
그래서 기본값은 조용한 앱도 목록에 유지하고 `현재 재생 중 아님`으로 표시합니다.
필요하면 설정에서 `재생 중인 앱만 보기`를 켜서 지금 소리가 나는 앱만 볼 수도 있습니다.

7. 프로그램 이름을 직접 바꿔서 보기 쉽게 정리
같은 실행 파일이 여러 세션으로 보이거나 표시명이 애매한 경우,
사용자 지정 이름을 저장해서 알아보기 쉽게 정리할 수 있습니다.

8. 업데이트·백업·로그도 현실적으로 정리

* 앱 안에서 새 버전 확인 및 자동 업데이트 (sha256 검증)
* 설정 내보내기 / 가져오기 — 다른 PC로 옮기면 장치 ID가 달라도 장치 이름으로 다시 찾아 줍니다
* 로그 자동 정리 (7일 보관, 최대 30개, 총 100MB 상한)
* 문제가 생겼을 때 경로·장치 ID 등을 가린 진단 패키지 만들기

이런 분들에게 특히 잘 맞습니다

* 스피커·이어폰·헤드셋을 다 꽂아 두고 상황에 따라 바꿔 쓰는 분
* 게임, 브라우저, 음악 앱, 디스코드 볼륨을 따로 관리하고 싶은 분
* 헤드셋 마이크와 다른 마이크를 자주 오가는 분
* 스트림덱으로 오디오 전환까지 버튼 하나로 하고 싶은 분
* Windows 기본 볼륨 믹서보다 빠른 관리 도구가 필요한 분

비슷한 도구와 다른 점
앱별 볼륨·출력 변경은 EarTrumpet, 단축키 장치 전환은 SoundSwitch 같은 좋은 무료 도구가 이미 있습니다.
DesktopAudioController는 그중에서도
"출력 + 마이크 + 대체 장치 + 장치 볼륨 + 앱별 출력"을 프로필 하나로 묶어 바꾸는 것,
스트림덱 명령 지원, 한국어 화면에 초점을 맞췄습니다.

설치 / 실행 방법

1. GitHub 릴리즈 페이지에서 최신 zip 파일을 다운로드합니다.
2. 원하는 폴더에 압축을 해제합니다.
3. DesktopAudioController.exe를 실행합니다.
4. 첫 실행 시 표시할 출력 장치를 설정합니다.
5. 설정창 > 수동 프로필에서 지금 상태를 프로필로 만들고, 프로필마다 출력·마이크·대체 장치·볼륨·단축키를 지정합니다.

별도 설치 프로그램 없이 바로 실행하는 방식입니다.
설정과 로그는 %LocalAppData%\DesktopAudioController에 저장되어, 새 버전으로 덮어써도 설정이 유지됩니다.
코드 서명이 없는 배포본이라 처음 실행할 때 SmartScreen("알 수 없는 게시자") 경고가 나올 수 있습니다.

최근 반영된 내용

v0.19.1

* 프로필에 기본 입력(마이크), 대체 장치 순서, 장치 볼륨·음소거, 프로그램별 출력 장치 추가
* 메인 화면 프로필 버튼, 트레이 프로필 목록(번호·단축키 표시), 툴팁에 현재 프로필 표시
* 프로필 전역 단축키
* 명령으로 프로필 적용 (--profile / --profile-index / --toggle-mute, 스트림덱 연동)
* 트레이에서 현재 출력 장치 볼륨 10% 단위 선택
* 장치를 바꾼 뒤 프로그램별 저장 볼륨을 패널을 열지 않아도 바로 적용
* Windows에서 바꾼 장치 볼륨을 화면·트레이에 바로 반영
* 기본 출력 장치를 맨 위에 표시
* 다른 PC로 옮긴 프로필의 장치를 이름으로 다시 찾기

개발하면서 중요하게 본 방향
이 프로그램은 단순히 기능만 넣는 것보다,
실제로 계속 써도 거슬리지 않게 만드는 쪽에 신경을 많이 썼습니다.
예를 들면:

* 목록이 불필요하게 깜빡이지 않도록 세션 표시 방식 조정
* 장치 목록 읽기·앱별 출력 변경처럼 멈출 수 있는 작업은 별도 프로세스로 분리해 메인 창이 멈추지 않게 처리
* 사용자가 직접 바꾼 볼륨은 프로그램이 다시 덮어쓰지 않도록 처리
* 로그는 디버깅 가능 수준은 유지하되 공개 첨부 리스크는 줄이기
* 배포는 single-file exe zip 기준으로 단순화

아직 남아 있는 과제
현재도 계속 다듬고 있는 프로젝트라 아래 부분은 더 보강할 예정입니다.

* 코드 서명이 없어 SmartScreen 경고가 뜨는 부분
* 프로그램별 출력 변경은 Windows 내부 기능을 쓰기 때문에, 일부 앱(게임·브라우저 등)은 다시 시작해야 바뀐 장치로 나오는 점
* 여러 장치·드라이버 환경에서의 세부 동작 다듬기
* v1.0 정식 버전을 위한 실사용 검증

마무리
Windows에서 장치별 / 앱별 오디오 제어를 자주 만지거나,
스피커·이어폰·헤드셋을 자주 바꿔 쓰는 편이라면
기본 볼륨 믹서보다 훨씬 빠르게 쓸 수 있는 도구가 될 수 있습니다.
필요한 기능을 실제 사용 흐름 기준으로 계속 다듬고 있으니,
직접 써보고 불편한 점이 있으면 피드백 주시면 반영해 보겠습니다.
