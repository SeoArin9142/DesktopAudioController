# DesktopAudioController 회귀 검증 체크리스트

## 목적

이 문서는 `v1.0.0` 직전과 이후 주요 릴리즈에서 반복 확인해야 할 핵심 시나리오를 고정합니다.

대상:

```text
- stable 후보 빌드
- v1.0.0 직전 최종 점검
- 장치/세션/트레이/업데이트 경로를 건드린 릴리즈
```

## 실행 전 공통 준비

```text
1. 테스트 대상 zip 압축 해제
2. 이전 실행 중인 DesktopAudioController 완전 종료
3. 필요 시 %LocalAppData%\DesktopAudioController\settings.json 백업
4. 로그 경로 비우거나 새 날짜 로그 기준선 확인
5. 테스트 대상 버전 기록
```

### C-6. 프로필 전환 (메인 화면 버튼 / 트레이 / 단축키 / 명령) / 마이크 / 대체 장치

```text
절차
1. 프로필 두 개(A, B)를 만들고 B에 기본 출력(꺼 둔 헤드셋) + 대체 1(다른 장치), 기본 입력(마이크),
   장치 볼륨(대체 장치 20%), 단축키(Ctrl+Alt+Shift+F12)를 지정한 뒤 저장
2. 메인 화면에서 A 버튼, 트레이 메뉴에서 B 항목을 차례로 누름
3. 단축키 Ctrl+Alt+Shift+F12 입력
4. 앱을 끈 상태에서 `DesktopAudioController.exe --profile "A"` 실행
5. 실행 중에 `--profile-index 2`, `--toggle-mute "장치 이름"` 두 번, `--profile "없는이름"` 실행

- 2: 누른 프로필이 파란색 / 체크로 표시되고 트레이 툴팁에 "프로필: 이름"이 보인다
- 1·2: 헤드셋이 없으면 대체 장치로 기본 출력이 바뀌고 "…가 없어 …로 대신" 알림이 뜬다.
       기본 입력(마이크)이 바뀌고, 대체 장치 볼륨이 20%가 된다
- 3: B가 적용된다. 다른 프로그램이 같은 단축키를 쓰면 설정 저장 때 등록 실패 안내가 뜬다
- 4: 창이 뜨지 않고 트레이로 시작해 A가 적용된다
- 5: 새 창 없이 실행 중인 앱에서 적용·음소거가 바뀌고, 없는 이름은 오류 알림이 뜬다
```

### F-2. 진단 패키지 생성 / 마스킹 확인

```text
절차
1. 설정창에서 "진단 패키지 내보내기" 실행
2. 생성된 zip 파일 열기

- 이슈 본문에는 raw 로그 전체가 아니라 redacted 요약만 들어간다
```
